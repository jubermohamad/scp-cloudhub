{{ if .Values.backfill.enabled -}}
1) Watch the DISTRIBUTED Day-0 backfill (driver + executors — trains Splink + resolves + loads Postgres):

     kubectl get sparkapplication {{ include "cpr.fullname" . }}-backfill-r{{ .Release.Revision }}
     kubectl get pods -l app.kubernetes.io/component=backfill-executor    # the executors
     kubectl logs {{ include "cpr.fullname" . }}-backfill-r{{ .Release.Revision }}-driver

   The UI comes up immediately; data appears once the SparkApplication reaches COMPLETED.
{{- else -}}
1) No build runs at install time. The UI comes up on an EMPTY store ({{ if .Values.api.builds.enabled }}/api/entities → [], /api/metrics → 404 "metrics not available" — both correct{{ else }}nothing will populate it: api.builds.enabled is false too{{ end }}). Trigger a build from the Builds page, or:

     curl -sX POST http://{{ if .Values.ingress.enabled }}{{ .Values.ingress.host }}{{ else }}localhost:8000{{ end }}/api/builds -H 'content-type: application/json' \
          -d '{"kind":"backfill","input_location":"{{ .Values.api.builds.messages.hostPath }}/smoke","reset_store":true,"note":"smoke"}'

   Datasets available to the dropdown = the immediate subdirs of {{ .Values.api.builds.messages.hostPath }} on the node (GET /api/builds/datasets).
{{- end }}

2) Open the UI:

     • kubectl port-forward svc/{{ include "cpr.web.fullname" . }} 8080:{{ .Values.web.service.port }}
       → http://localhost:8080/

     • API:      kubectl port-forward svc/{{ include "cpr.api.fullname" . }} 8000:{{ .Values.api.service.port }}  → /docs
