# AKS cluster tfvars

One `<cluster-name>.tfvars` per AKS cluster, generated by the CloudHub portal's
Create AKS Cluster flow (`/create/aks`). Files are committed by the portal to a
`feature/create-aks-<cluster>` branch and merged into `main` via pull request.

Cluster naming: `aks-<customer>-<environment>-<region>` (see
`InfrastructureProvisioningService.buildClusterName`).

Each new cluster is also registered in
[`infra/workspacemanager/workspaces.tfvars`](../../workspacemanager/workspaces.tfvars).
