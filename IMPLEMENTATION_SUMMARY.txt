DEPLOYMENT WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User Request (Deployment Wizard)
2. Status: PENDING (saved to database)
3. Platform Admin Reviews (PendingApprovalsPage)
4. Admin Approves/Rejects
5. If Approved:
   - Helmfile generated dynamically
   - Committed to temporary GitHub branch
   - Workflow dispatched (deploy-with-dynamic-runners.yml)
   - Status: VALIDATING → DEPLOYING
6. Deployment completes
7. Status: DEPLOYED or FAILED
8. Audit trail recorded
9. User notified
